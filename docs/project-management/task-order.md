## 1. 과업 배경 및 목적

### 1.1 배경

농업기계 자율주행 소프트웨어(A-SW) 개발은 다양한 분야의 전문 기술이 융합되어야 하는 복잡한 과제로, 5개 참여기관(KITECH, TYMICT, JBNU, VIA, OntarioTech) 간 효율적인 협업 체계가 필수적입니다.

기존의 이메일, 파일 공유 방식의 협업은 다음과 같은 한계가 있습니다:
- 실시간 협업 제한으로 인한 개발 주기 지연 (3-6개월)
- 코드 통합 시 버전 충돌 및 품질 문제
- 빌드/배포 과정의 수동 처리로 인한 비효율
- 프로젝트 진행상황 추적 어려움

### 1.2 목적

본 과업은 농업기계 자율주행 소프트웨어 개발을 위한 **통합 협업 플랫폼(A-SW Hub)**을 구축하여, 참여기관 간 실시간 협업 체계를 확립하고 개발 효율성을 75% 이상 향상시키는 것을 목적으로 합니다.

## 2. 과업 범위

### 2.1 핵심 기능

#### 2.1.1 인증 및 권한 관리
- Email/Password 인증 + GitHub OAuth 2.0 통합
- 역할 기반 접근 제어 (RBAC): Admin, Developer, Viewer
- JWT 기반 세션 관리 및 자동 갱신

#### 2.1.2 프로젝트 관리
- 농업기계 A-SW 프로젝트 통합 관리
- Git 저장소 연동 (GitHub/GitLab)
- 프로젝트 설정: General, Repository, Build, Deployment, Notifications
- 협업자 관리 및 권한 설정

#### 2.1.3 CI/CD 파이프라인
- 자동 빌드 트리거 (Git Push → Build → Test → Deploy)
- 실시간 빌드 로그 스트리밍
- 9단계 빌드 프로세스 시각화
- 빌드 실패 시 자동 알림 및 롤백

#### 2.1.4 배포 관리
- 다단계 배포 환경: Development, Staging, Production
- 배포 승인 워크플로우
- 배포 히스토리 추적

#### 2.1.5 품질 관리
- 코드 품질 메트릭: Coverage, Complexity, Duplication
- 다단계 승인 워크플로우 (2-tier approval)
- 품질 게이트 자동 검증

#### 2.1.6 대시보드 및 모니터링
- 실시간 KPI 대시보드
- 빌드 성공률, 배포 빈도, 평균 리드타임 추적
- 활동 피드 및 알림
- 언어별 프로젝트 분포 시각화

#### 2.1.7 타임라인 관리
- 5개년 계획 Gantt Chart 시각화
- 136개 산출물 진행상황 추적
- 기관별/년도별 태스크 계층 구조
- 마일스톤 및 의존성 관리

### 2.2 기술 요구사항

- **Frontend**: SvelteKit 2.x, TypeScript 5.x (Strict Mode)
- **State Management**: Svelte Stores
- **Validation**: Zod (런타임 타입 검증)
- **Visualization**: Chart.js
- **Design**: Extreme Black & White Industrial Design
- **Testing**: Vitest (Unit), Playwright (E2E)
- **Build**: Zero TypeScript Errors, Zero Warnings

### 2.3 비기능 요구사항

- **성능**: Lighthouse 점수 Performance 95+, Accessibility 100
- **보안**: HTTPS Only, OAuth 2.0, JWT, RBAC, CORS, CSP
- **접근성**: WCAG 2.1 AA 준수
- **브라우저**: Chrome 90+, Safari 14+, Firefox 88+
- **반응형**: Desktop (1024px+), Tablet (768px+), Mobile (< 768px)

## 8. 특기사항

### 8.1 설계 원칙
- **Extreme Black & White Industrial Design**: 오직 #000000과 #FFFFFF만 사용, border-radius: 0
- **Configuration-Driven Architecture**: 환경 변수 기반 동작 제어
- **Domain-Driven Design**: 도메인별 독립적 모듈 설계
- **Zero-Touch Deployment**: 코드 푸시부터 배포까지 완전 자동화

### 8.2 제외 범위
다음은 본 과업 범위에서 **제외**됩니다:
- 실제 농업기계 하드웨어 제어 인터페이스
- AI/ML 모델 학습 및 추론 엔진
- 실시간 센서 데이터 수집 시스템
- 모바일 네이티브 앱 (웹 반응형으로 대체)
- 백엔드 API 서버 구축 (Mock 데이터 사용)

### 8.3 지적재산권
- 본 과업의 모든 산출물에 대한 지적재산권은 **발주기관(KITECH)**에 귀속됩니다.
- 오픈소스 라이선스가 적용되는 외부 라이브러리는 해당 라이선스를 따릅니다.

### 8.4 변경 관리
- 과업 범위 변경 시 발주기관과 수행기관 간 서면 합의 필요
